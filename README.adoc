= Org infra template

Reusable Pulumi + Antora skeleton for org infra repos.

link:https://github.com/dev-centr/infra-template/issues[Report Bug] ·
link:https://github.com/dev-centr/infra-template/issues[Request Feature]

== About The Project

Reusable Pulumi (TypeScript) + Antora docs skeleton for a GitHub organization's central `infra` repository.

Copy or use as the source when DevCentr bootstraps an org-level infrastructure repo.

=== Layout

----
Pulumi.yaml
package.json
tsconfig.json
src/index.ts
docs/
README.adoc
.gitignore
----

Strategic email/vendor choices: link:https://github.com/dev-centr/business-bootstrap[business-bootstrap].

== Installation

Copy this template into your org's `infra` repository, then:

[source,bash]
----
pnpm install
pulumi up
----
